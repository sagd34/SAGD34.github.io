# HTML / CSS / JavaScript 速查表 · 项目说明

一个**纯静态、零依赖、离线可用**的前端速查站点：收录 HTML 标签、CSS 属性与 JavaScript 常用写法，每条内容都配**可编辑、可运行的实时演示**，并允许用户自行补充条目。数据保存在浏览器本地，无需登录、无需后端、无需联网。

- 版本：`?v=14`（资源版本号写在 `index.html` 引用后面，改动资源后需同步 +1 以绕过缓存）
- 署名：2026年 · 26大数据2 · 丘顺辉

---

## 一、快速开始

三种方式任选其一：

1. **直接打开**：双击 `index.html`（`file://` 协议即可完整使用，localStorage 正常读写）。
2. **本地静态服务器**（推荐，行为与线上一致）：
   ```bash
   cd "HTML标签学习网页"
   python -m http.server 8000
   # 浏览器访问 http://localhost:8000
   ```
3. **部署**：把整个目录丢到任意静态托管（Nginx / GitHub Pages / OSS / 内网静态服务）即可，没有构建步骤。

浏览器要求：较新的现代浏览器。项目用到了 `:has()`、`color-mix()`、`ResizeObserver`、`<iframe srcdoc>`，建议 Chrome / Edge 111+、Firefox 121+、Safari 16.4+。

## 二、技术选型

| 项 | 选择 | 说明 |
|----|------|------|
| 构建 | **无** | 没有打包器、没有 Node 依赖，改完刷新即生效 |
| 框架 | **无** | 原生 JavaScript（ES5+ 写法，兼容性优先） |
| 路由 | Hash 路由 SPA | `#/tags`、`#/css/props`、`#/js` 等，`hashchange` 驱动渲染 |
| 样式 | 单个 `main.css` | CSS 变量驱动主题，`html[data-theme]` 一键换肤 |
| 语法高亮 | 自研 `highlight.js` | 约 350 行的轻量高亮（`window.HL`），不引第三方库 |
| 代码演示 | `<iframe srcdoc>` 沙盒 | 与页面样式隔离，脚本在受限沙盒中运行 |
| 数据存储 | localStorage | 通过 `store.js` 统一读写，键前缀 `htmlcheat.` |

## 四、实时演示（核心机制）

- 每个演示是一段 HTML + CSS + JS，注入到 `<iframe srcdoc>` 中运行，`sandbox="allow-scripts allow-modals allow-popups allow-forms"`，**无同源权限**，无法访问页面本身或用户数据。
- 预览区会自动注入当前主题的 CSS 变量（`--accent`、`--bg-elev` 等），所以演示里的配色与站点主题一致；切换主题时所有演示重绘。
- 沙盒内 `localStorage` 会因无同源而抛错，因此注入了一份内存版 storage shim，并把数据回写到宿主 `demoStore` 中持久化。
- 控制台桥接：演示里的 `console.log / warn / error` 与未捕获异常会汇总成右侧徽章，展开可看逐条输出。
- 演示工具条：代码自动换行开关、行号开关、字号调节（12–18px）、⛶ 全屏（Esc 退出）、⟳ 重跑、⧉ 复制、↺ 还原。
- 布局：默认**左右分栏**，中间可拖拽分隔条调整宽度；窗口宽度 < 768px 自动改为**上下堆叠**并可拖拽调整高度；双击分隔条恢复 5:5。编辑区默认高度不低于 320px（约 40vh）。比例与高度按演示 id 记入 localStorage，下次打开沿用。
- 快捷键：`Ctrl / ⌘ + Enter` 运行、`Ctrl / ⌘ + S` 刷新预览、`Tab` 插入两空格缩进。

> **已知限制**：给 `srcdoc` 重新赋值不会重跑其中的脚本（浏览器行为）。因此修改代码后靠输入事件实时重绘；如果需要重新执行一遍 JS，用 **⟳** 或 `Ctrl / ⌘ + Enter`。

## 五、自定义数据与本地存储

侧边栏「＋ 添加自定义内容」可添加四类内容，均带 **✦ 自定义** 角标、支持详情／编辑／删除／复刻，并参与全站搜索与筛选：

| 类型 | 存储键 | 出现位置 |
|------|--------|---------|
| 🏷 HTML 标签 | `htmlcheat.customTags.v1` | `#/tag/<名>` |
| 🎨 CSS 属性 | `htmlcheat.customCss.v1` | `#/css/prop/<名>`、`?custom=1` |
| ⚡ JS 条目 | `htmlcheat.customJs.v1` | `#/js/ex/<名>`、`?custom=1` |
| 📦 代码示例 | `htmlcheat.mySnippets.v1` | `#/mine/<名>` |

站点偏好统一存在 `htmlcheat.settings.v1`（主题、动效开关、侧栏状态、顶栏是否隐藏、演示 UI 偏好与尺寸等）。

**校验规则**：名称必填；禁止 `< > / \ " ' =`；标签与 CSS 属性只允许英文标识符；与内置或已有自定义条目重名会被拦截。

**备份与迁移**：`#/manage` 页面可导出 / 导入 JSON（四类数据分别或整体），也可一键清空。数据只在这台浏览器里，清理浏览数据前请务必先导出备份。

## 六、界面与体验

- **16 套主题**：8 套风格主题（二次元、科技、田园、学校、赛博朋克、萌系、大自然、IT）+ 8 套经典配色（靛蓝、暖纸、松林、樱花、紫罗兰、深海、午夜、石墨）。风格主题各自带**动态特效层**（花瓣、网格、流云、横线纸、霓虹、星光、落叶、代码雨），可用主题面板底部的开关一键关闭全部动效；选择会被记住。
- **顶栏**：滚动进度条、图片态阴影加深；右侧依次为「隐藏顶栏」「主题」「打印」。
- **沉浸模式**：按 `H` 或点按钮收起顶栏，侧边导航与页内大纲自动贴顶并铺满视口，顶部浮出「显示顶栏」提示；再按 `H` / `Esc` 或点浮标恢复。窄屏（≤860px）自动禁用（那里顶栏就是导航入口）。
- **侧边导航**：宽屏可整体收起（246px → 0），窄屏变抽屉；状态记忆。
- **页内大纲**：CSS 属性页与 JS 页左侧的大纲**严格按 h1 → h2 → h3 …（最多 h6）**生成，不允许跳级，同级自动编号（`1` / `1.2` / `1.2.3`），滚动自动高亮并展开当前分支；搜索过滤时大纲同步筛选，父级显示命中数量。
- **响应式**：1240px 以下收起左侧大纲，换成页内横向跳转条；900px 以下隐藏演示区脚注；860px 以下侧栏抽屉化、顶栏出现 ☰；768px 以下演示区自动改为上下堆叠（分隔条变横向）。
- **打印友好**：`Ctrl / ⌘ + P` 或点 🖨️ 打印，样式会隐藏交互控件、展开代码并把演示改成适合纸张的高亮浮层，底部署名保留。
- **无障碍**：跳转链接、语义标签、`aria-*` 标记、focus 可见、大纲 / 导航均为可聚焦按钮。

## 八、维护与扩展

**新增内置数据**：直接编辑对应的 `data-*.js`——标签写进 `TAG_DATA`（字段：`n` 名称、`d` 说明、`c` 分类、`s` 状态、`void`、`a` 属性数组、`demo` 示例等），CSS 属性写进 `CSS_PROPS`，JS 条目写进 `JS_GROUPS.items`，综合实例写进 `JS_EXAMPLES`。页面会自动带上它们，搜索索引同步生效，无需改渲染代码。

**新增演示**：给 CSS 属性 / JS 条目补上 `html` `css` `js` 字段即可生成三栏演示；`CSS_SNIPPET_DEMOS`、`JS_GROUP_DEMOS` 用于给片段和分组挂载独立的「运行效果」示例。

**新增主题**：在 `app.js` 的 `THEMES` 数组加一项（`id` / `name` / `mode` / `fx`），并在 `main.css` 里补一组 `html[data-theme="<id>"]` 的 CSS 变量（至少 `--bg`、`--bg-elev`、`--bg-soft`、`--text`、`--text-soft`、`--text-dim`、`--accent`、`--accent-soft`、`--border`、`--border-st`）。建议顺手核对正文对比度（正文 ≥ 7、次要文字 ≥ 4.4、强调色 ≥ 3）。

**改了静态资源**：把 `index.html` 里 `main.css?v=N` 与 `*.js?v=N` 的版本号统一 +1，避免用户浏览器还在用旧缓存。

## 九、注意事项

- 站点完全离线，不请求任何外部接口、不上传任何数据；自定义内容只存在当前浏览器。
- 演示沙盒允许执行任意脚本，请勿粘贴来源不明的代码后在其中输入敏感信息。
- 换浏览器、清理浏览数据或使用无痕窗口都会导致自定义数据不可见，务必先在「数据管理」导出 JSON。
- 页面脚本较多时（如 JS 速查页同时挂载 10 组示例）已做懒加载，但一次打开过多演示仍会消耗较多内存，建议按需运行。
